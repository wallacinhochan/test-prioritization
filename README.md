# Test Prioritization

Repositório de pesquisa sobre seleção e priorização de testes. A etapa inicial avalia o Apache Commons Lang como candidato a objeto experimental.

## Meta atual — Entrega 3: resultados preliminares

A meta desta rodada é produzir resultados preliminares da pesquisa. O piloto usa o Apache Commons Lang e adota o método como unidade de teste. A decisão definitiva sobre o projeto estudado será registrada na KAN-12 após a auditoria das falhas históricas.

A entrega preliminar deve registrar as revisões executadas, os resultados e as durações do T0 por método, as falhas observadas e as limitações da amostra. Quando houver dados comparáveis, incluir uma primeira comparação com uma estratégia de seleção e informar quantas revisões ela cobre.

As evidências de cada tarefa ficam no repositório, com resumo e referência no Jira. As decisões técnicas rotineiras ficam com os responsáveis pelos cartões. Mudanças de projeto, recorte, ambiente que afete a comparabilidade ou métricas são submetidas a Wallace com evidências, alternativas e recomendação.

O [relatório de resultados preliminares](evidencias/ENTREGA-3/README.md) reúne os cinco T0 verificados e os limites do piloto.
